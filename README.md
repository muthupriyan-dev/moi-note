# 📒 Moi Note

Moi Note is a simple Progressive Web App (PWA) for managing Moi (gift) records digitally. It helps users record, search, and organize contributions easily.

## ✨ Features

- ➕ Add Moi records
- 🔍 Search records
- ✏️ Edit existing records
- 🗑️ Delete records
- ☁️ Firebase Firestore integration
- 🔐 Firebase Authentication
- 📱 Progressive Web App (PWA)
- 🌐 Works on mobile and desktop

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Service Worker
- Web App Manifest

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/muthupriyan-dev/moi-note.git
```

2. Open the project folder.

3. Configure Firebase by updating `firebase-config.js`.

4. Open `index.html` in your browser or use a local server.
